# Design

## Colors

- Ink: `#29251f` for primary text and icons.
- Muted: `#827a70` for secondary text.
- Canvas: `#faf8f4` for the page background.
- Surface: `#ffffff` for cards and controls.
- Border: `#ece7df` for subtle dividers.
- Tomato: `#e56b45` for primary actions and highlights.
- Tomato dark: `#c85332` for hover and pressed states.
- Herb: `#63816a` for positive or ready states.
- Butter: `#f5e6bf` for warm secondary surfaces.

## Typography

- Use the system sans-serif stack for a fast, native feel.
- Use a bold weight for page titles and recipe names; regular weight for body copy.
- Keep supporting text comfortably readable at 14px or larger.

## Spacing and shape

- Use a 4px spacing scale, favoring 8px, 16px, 24px, and 32px increments.
- Use 12px corner radii for controls and 18px for larger cards.
- Use subtle borders and soft shadows; avoid heavy outlines.
- Start with a 16px mobile page gutter and widen it on larger screens.

## Layout

- Keep the recipe library mobile-first and single-column on narrow screens.
- Use a persistent sidebar and multi-column recipe grid only when there is room.
- Keep primary actions easy to reach and tap on a phone.
